# Exposed Diversity Index

**Measuring the diversity a recommender feed actually exposes — and testing what we think we know about it.**

---

## What this repository contains

An **instrument** — a measure of the diversity a news feed actually exposes to its reader,
computable without access to the platform's code — and the **adversarial method** that put it to
the test: every proposition here is attacked, and whatever falls is published as fallen.

What remains: eighteen executable notebooks, 556 tests, seventeen recorded corrections, and a
state of affairs that does not resemble what the project announced.

## The verdict, in one page

| Object | State |
|---|---|
| The quantum decoherence ↔ consensus collapse analogy | **refuted**, transfer by transfer — nothing specifically quantum survived it → [audit](limites.en.md) |
| The classical formalism it led us to borrow | **coherent, and it reproduces behaviours**, but only one parameter is calibrated, and its one proper prediction — the effect of emotional charge — was **tested four times with no effect** |
| The index as it was proposed to the regulator | **untenable**: saturable at zero cost, then circumvented by burial → [adversarial test](gaming.en.md) · [adversarial rank](rang-adverse.en.md) |
| The retained form of the index | **defined and costed** — entropy of served items, rank-weighted — but **never tested on a real feed** |
| The algorithm (EDA) | **not evaluated**, and not evaluable on public data as things stand → [logs that record the rank](rang-servi.en.md) |
| The persistence gap between emotional registers | **does not exist** — it was a selection artefact → [extended corpus](corpus-etendu.en.md) · [annotation](annotation.en.md) |
| The measuring instruments built along the way | **valid**, and one of them confronted with a ground truth → [served rank](rang-servi.en.md) |

**In one sentence: the theory did not hold, the metrology did.**

## What holds

**A check that says whether a recommender log is even correctable.** The within-feed
exchangeability test detects nothing in MIND ($z = +0.12$, shuffled order) and rejects at
$z = -206$ on Baidu-ULTR, on the side theory prescribes. It is exact, power-calibrated, and it
must precede any exposure estimate.
→ [MIND's exploration](mind.en.md) · [Logs that record the rank](rang-servi.en.md)

**A position-bias severity that is estimated rather than posited.** $1.10 \pm 0.09$ on a search
results page; **ten times less** on a three-thumbnail banner, where random allocation makes the
measurement causal. $\eta$ is a property of the **surface**, and transporting it costs up to
+179 % on the published figure. → [Adversarial rank](rang-adverse.en.md)

**Counterfactual estimators checked against a ground truth.** The value of a never-deployed
policy, estimated from another policy's data alone: **+2.5 %** error, against **+32 %** for the
naive estimate — with the diagnostic that forbids declaring victory, an effective sample size of
1,513 out of 4 million impressions. → [Logs that record the rank](rang-servi.en.md)

**A data access request that can be verified instead of argued.** Four aggregate tables, with no
personal data, proven to recompute the measurements **identically** — for 95 times fewer rows
than the raw log. → [Article 40 data request](article-40.en.md)

## What fell

Six negative results, each published with what established it:

* **the $\gamma\alpha > \lambda$ criterion means nothing** — it holds by construction for any
  content that broke through, which only measurement revealed
  → [calibration](calibration.en.md);
* **the persistence gap between registers does not exist** — ×9.2 versus ×2.9 on the pilot
  corpus, ×3.04 versus ×2.90 ($p = 0.53$) across 440 subjects
  → [extended corpus](corpus-etendu.en.md);
* **it was not diluted by labelling** — 40 % noise measured, and the gap disappears anyway
  → [blind annotation](annotation.en.md);
* **an index floor saturates at zero cost** — 1.000 for zero content diversity
  → [adversarial test](gaming.en.md);
* **the first fix prescribed polarisation** — the constrained optimum of Rao's entropy is
  bimodal → [adversarial test](gaming.en.md);
* **the reference dataset does not permit the announced evaluation** — MIND does not keep the
  served order, and no public dataset carries both rank and viewpoint labels
  → [MIND](mind.en.md) · [served rank](rang-servi.en.md).

## What is not settled

* **The retained form of the index has never been measured on a real feed.** It is defined, its
  engagement cost is quantified in simulation, and that is all.
* **The level of the floor is a political decision**, as is the viewpoint catalogue that serves
  as its grid. The measurement describes; it does not prescribe.
* **The three annotation coders are instances of the same language model.** Agreement among them
  necessarily overstates what independent judges would produce.
* **Nothing demonstrates that human opinion *obeys* statistical mechanics.** The work
  establishes that a formalism borrowed from physics **reproduces** some of its behaviours.

## The two instruments

| | Object | State |
|---|---|---|
| **[EDI / IDE](ide.en.md)** | *Exposed Diversity Index* — entropy of served items over the declared reference catalogue, **weighted by the attention of each rank**, in $[0, 1]$ | retained form **defined**, untested on real data |
| **[EDA / ADE](ade.en.md)** | *Exposed Diversity Algorithm* — a recommender filter optimising this index rather than raw engagement | **not evaluated**: the dataset that would allow it does not exist publicly |

French acronyms **IDE** and **ADE** are used throughout the code and the French documentation;
**EDI** and **EDA** are their English equivalents.

The [regulatory memorandum](memorandum.en.md) turns the index into recommendations for national
and European regulators under the Digital Services Act — each recommendation carrying the
measurement that corrected it.

## Where this came from

The project started from an analogy: the larger a quantum system, the faster it decoheres; the
larger a population, the harder agreement becomes. That analogy produced measurable quantities,
and **none of its own claims survived verification**. That is the subject of the [critical
audit](limites.en.md), which records **seventeen corrections** — five of which invalidated a
formula, and two of which were discovered by trying to measure.

What survives of the formalism is classical: free-energy landscape, phase transition, hysteresis,
barrier crossing.

## Reproduce

Everything runs in containers. Nothing is installed on the host.

```bash
git clone git@github.com:s-geffroy/Index-Dissipation-Entropique.git
cd Index-Dissipation-Entropique

docker compose run --rm test          # 556 tests
docker compose run --rm notebooks     # regenerate every figure
docker compose up lab                 # JupyterLab on :8888
docker compose up site                # this documentation on :8000
docker compose run --rm latex         # compile the paper to PDF
```

The English paper is at `paper/synthesis_note.tex`.
